# Siri-Dhanya Hub

## Project Description
Siri-Dhanya Hub is an Android application developed to promote millet awareness, healthy food habits, and agriculture support. The application provides millet market prices, millet recipes, health benefits, and direct farmer connectivity through a user-friendly interface.

## Features
- Mandi Watch for millet price tracking
- Recipe Lab with search functionality
- Health Benefits section
- Direct Buy section
- Favorite recipe saving
- Splash screen and smooth navigation

## Technologies Used
- Android Studio
- Kotlin
- XML
- RecyclerView
- SharedPreferences
- Glide Library

## Project Modules
1. Home Screen
2. Mandi Watch
3. Recipe Lab
4. Recipe Detail Page
5. Health Benefits
6. Direct Buy
7. Splash Screen

## How to Run the Project
1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle files
4. Run the application on Emulator or Android Device
